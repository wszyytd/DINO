# 全状态更新与真实观察价值诊断

用户已同意继续执行对话中确定的两项：推广稳定更新至全部价值训练状态，加入真实后续特征价值诊断。沿用当前工作树，作者自行实现复核，不新增不必要子代理。

## 范围与取舍

保持 DINO、适配器、记忆和匹配器冻结；收益仍为 relative_softmax_v2 的真实身份 margin 增量。原 96 个训练记录去重后使用全部 87 个，不按收益过滤。正式飞行入口不获得未来特征。

比较 direct_single、direct_joint、observation_zero_joint、observation_real_joint。前两者比较更新方式；后两者结构、参数量和初始化相同，仅改变是否提供真实未来特征，排除仅增加参数量的解释。观察头复用当前动作表示，加一个零初始化输出的观察残差分支；真实观察使用冻结 encode_observations 的 5×dim tokens（当前源实验 dim=64），保留 token 位置，失败观察置零并标记无效。输入不包含身份真值或动作后的匹配分数。

joint 保持奇数步困难状态均匀、偶数步全部状态均匀的阶段期望权重；每状态内部平均合法动作损失。分块累积梯度时每块使用全局权重，只在完整梯度后裁剪和更新一次。报告优化器更新次数、处理状态和动作数量，不能把等更新次数称为等算力。

开发评估使用源运行中已有 eval 角色（位置 105，曾用于开发），与训练图片/场景组/位置隔离，但身份重合、参考背景未隔离，不是新独立测试。显式 --include-development 才加载其特征；固定 seed=7 的状态生成，两个分支与所有条件共用状态/动作，不按标签筛选。不选择最优开发检查点；最终固定步数评估并保留逐状态预测与分组结果。正式 rollout、停止阈值和预留测试不变。

## 实验

先做 seed 7、两表征分支、四条件、各 2000 次更新，lr=1e-4，AdamW wd=.01，clip=5。每 50 步记录训练指标；独立记录共同处理状态数时的检查点。开发集只在最终检查点评估。三种子复现命令随后交付；不把一个优化种子当独立数据集。

报告 MSE、按阶段权重加权 MSE、动作 regret、相对随机 regret、有效差异动作对排序、收益明显状态子集及按拍摄配置聚合的结果。真实特征条件是特权诊断，不是可部署策略或严格上界。它改善只支持未来观察信息值得建模；无改善也不能证明信息无用。

## 交付与验收

新增隔离诊断模块、CLI、针对梯度权重/动作对齐/未来信息隔离的测试、报告和本地实跑。源 checkpoint、标签和特征清单保持哈希不变；输出目录存在时拒绝运行。异常运行写 failed 状态。诊断 checkpoint 标记 diagnostic_only，并由正式 value 加载器明确拒绝。

本轮不训练视角预测器、不扩采、不更换价值标签、不将这些结果称作无人机闭环性能。
