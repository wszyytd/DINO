# 扩采参考引导匹配照片

目前模型在训练的两辆车上能拟合，CLS基线也排对全部10组，尚未证明对新车、新参考有效。本次扩采增加参考变化和独立验证，不以继续降低旧训练集loss为目标。

## 本次计划

`collect_match_photos.py`从服务器实际CARLA资产中选择8个有颜色属性的四轮车型，分给训练4个、验证2个、测试2个。默认不选警车、救护车等带明显装备或涂装的车辆，减少仅记警灯的捷径；实际车型仍需查看采集计划和照片确认。

程序从当前地图出生点选择9个相隔至少80米的位置，三个划分各用3个。每组两辆车用相同配置颜色，交换槽位并改变朝向，在正午和低太阳高度条件下拍摄。每组两辆车分别作为参考，均重新拍参考图，不复用旧的唯一白车参考。

查询相机的方位以场景出生点朝向为基准，与哪辆车是真目标无关。只交换参考身份时，不让查询相机跟着目标车转向，避免把真值目标的信息写进取景方式。参考图仍围绕其对应车辆拍摄。

| 划分 | 车型资产 | 位置 | 参考采集场景 | 查询裁剪 | 参考裁剪 |
|---|---:|---:|---:|---:|---:|
| train | 4 | 3 | 24 | 480 | 24 |
| val | 2 | 3 | 12 | 240 | 12 |
| test | 2 | 3 | 12 | 240 | 12 |
| 合计 | 8 | 9 | 48 | 960 | 48 |

原始相机2048×1536，每个场景10个共享查询视点。包括高空、下降、侧面、前后斜侧、另一侧及较高斜视。1008是计划导出的车辆裁剪数，不是独立场景数量，也不保证每张图都能辨认身份。

这些是同一地图内未见车型资产、未见位置的检查，不是跨地图或现实泛化。车辆实例编号A/B只在各次场景中有意义；正负标签表示候选是否与该次参考属于同一实例。

## 服务器采集命令

先保持CARLA仿真器运行。在另一个终端执行以下命令。采集用`carla10`，不是训练用的`dino-probe`。

```bash
cd /mnt/fast18/sunbo/DINO
git pull --ff-only origin main
conda activate carla10

# 只读服务器资产和地图，打印实际可采计划，不拍照、不建立输出目录
python collect_match_photos.py --dry-run

# 实际采集，输出目录自动按时间命名，保留旧数据
python -u collect_match_photos.py
```

需要空的受控场景。不会删除其他车辆或切换地图。若已有同步tick主控，先停止该客户端再决定是否明确使用`--take-tick-ownership`。找不到8种车型、9个满足间距的位置，或连接失败时会在拍照前停止，不替换成不存在的资产。

若车辆无法生成、静止检查失败、截图无效或清理失败，采集立即停止，保留已拍图片和`collection.json`错误记录。不要直接重用或删除失败目录以掩盖问题，提供报错及首组预览后调整配置，再使用新运行目录。

## 采完先看什么

实际输出位置会在终端打印，例如`data/more_photos_日期时间`。检查：

- `collection.json`必须为complete，48个场景完成。
- `index.html`可逐组查看真实图片。各车型实际颜色和涂装需看图核实。
- 留意遮挡、两车重叠、图像过小、参考是否清楚。真值包围盒只给位置，不证明可见或可辨认。
- `pairs_train.json`、`pairs_val.json`、`pairs_test.json`只在全部采集成功并通过跨划分图片检查后输出。

现有高空或远景即使标签正确，也可能没有足够辨识信息。不能把标签存在当作每张图片都必须有高置信度的依据。

## 训练和独立评估

采集完成后切回训练环境。为了不再复制路径占位符，下面用Python自动选择本目录中最近一次**完成**的扩采运行；会在命令开始前打印该目录。

```bash
conda activate dino-probe
python train_more_photos.py --device cuda --epochs 30 --dry-run
python -u train_more_photos.py --device cuda --epochs 30
```

训练阶段使用train，选模型使用val；test只在选出验证最优模型之后评估一次。脚本保留每次独立的训练输出，不覆盖旧模型。实际测试结果仍需与CLS基线比较，并检查失败样例，不能只看训练集成绩。

## 本地验证边界

本地可测试计划、车型／位置划分、A/B参考平衡、流程失败停止，以及合成文件的数据流。合成测试不是CARLA渲染结果。本次真实1008张照片需要上述服务器采集完成后才存在。

新增测试检查划分不重叠、正负标签平衡、完整合成采集流程、失败保留状态、交换参考时查询相机几何不变，以及验证选模型后再运行测试集的训练命令顺序。
