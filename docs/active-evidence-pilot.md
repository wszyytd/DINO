# 流形辅助的主动证据收集：离线实验

2026-11-04 更新：默认改用相对 softmax 分数，新增冻结上游重训价值头、分组学习曲线及扩采恢复入口。后续服务器执行请用 [v2 操作说明](evidence-experiment-v2.md)；下文保留首轮实验记录。

实现入口为 `run_evidence_pilot.py`，不启动 CARLA，也不重新提取 DINOv2 特征。它从已有多视角照片和实际位姿重放“观察候选车辆 → 更新记忆 → 匹配参考图 → 选择下一视角”。

## 实现内容

1. 冻结 DINOv2，训练特征适配器、集合记忆和参考条件匹配器。
2. 用记忆和目标相对位姿预测冻结教师的 CLS 与 2×2 区域特征。预测损失是训练辅助；预测图像特征不写入在线记忆。
3. 冻结上游，以真实新观察前后的目标匹配 margin 差生成标签。另训动作价值网络，输入参考表示、所有候选记忆、当前分数、观察次数、待观察候选及位姿。
4. 在相同预算下比较随机、固定顺序、视角覆盖、价值引导及单步贪心 oracle，并运行 CLS 均值基线。

这版通过“已见多视角 → 未见位姿特征”的预测任务利用视角结构，不显式拟合一个几何流形，也不把流形假设当成网络一定有效的证明。动作价值直接预测收益；没有接入 `G(m, D(m,v))` 的在线预测链。

## 数据与边界

首轮读取 `more_photos_20261028_030040_745590/train` 中 26 个完整拍摄任务；跳过 1 个未完成任务。位置 42 的 10 个任务训练表征，位置 64 的 8 个任务训练价值头，位置 105 的 8 个任务评测。车型身份重叠，参考和候选仍来自同一背景；这里的 8 个评测任务不是 8 个独立位置。

位姿使用记录中的真实 camera_pose、target_pose，转换到车辆坐标系；不把拍摄脚本里的公共轨道名称当成目标相对位姿。候选与动作建立后，失败结果保留并消耗预算；只有观察到的新图像才能进入记忆。重复观察 ID 或“图像哈希＋位姿”不重复写入。

集合聚合保证观察顺序不变，重复帧幂等由更新器的去重实现，普通 attention pooling 本身并不天然幂等。输入图像及特征文件经过哈希校验；数据角色之间的精确重复图片会被拒绝。

这是位置隔离的流程试验。默认关闭提前确认，因此任务状态会是 `UNRESOLVED`；主要输出是固定预算下的正确排序率。`--stop-gap` 只供未校准的停止诊断，不应把其确认率作为正式识别效率。正式的“达到可靠识别阈值所需观察数”还需独立校准数据。

## 运行

依赖沿用项目的 PyTorch、NumPy 和 Pillow。已验证环境是 CPU PyTorch；本机 Python：

```powershell
& 'D:\Data\Notes\Obsidian\计算机\科研\DINO-attention-20261024\.venv\Scripts\python.exe' -X utf8 -u run_evidence_pilot.py `
  --data 'D:\Work\DINO\data\more_photos_20261028_030040_745590\train' `
  --cache 'D:\Work\DINO\out\more_photos_20261101_135207_870565\features' `
  --output 'out\active_evidence_new_run' `
  --allow-pilot-location-split --device cpu --threads 2 `
  --memory-steps 120 --value-steps 300 --states-per-episode 12 --budget 8
```

先检查元数据可增加 `--dry-run`。每次正式运行必须使用新的输出目录；程序拒绝覆盖已有实验。

使用已有 GPU 环境时可以传 `--device cuda`，但本轮没有验证 GPU 数值结果。首轮固定种子 7、维度 64、记忆 token 数 4，原 16×16 patch 网格池化到 8×8。教师目标从池化前特征生成。比较 `alpha=0` 和 `alpha=0.1`；两者的匹配训练抽样与历史顺序相同，辅助目标抽样使用独立随机数发生器。

输出包含：

- `run.json`、`data_audit.json`：参数、数据来源、分组、源码哈希及完成状态。
- `alpha_*/memory/`：表征检查点、训练记录、冻结特征配置。
- `alpha_*/value/`：价值检查点、真实转移标签及上游模型指纹。
- `*/policies.json`、`*/traces.json`：预算曲线、逐步动作、失败尝试与分数。
- `report.md`：结果表及解读边界。

检查点加载会拒绝不同特征配置或上游模型指纹。训练选择固定步数的最后检查点，不在评测位置上选模型。

统计中 `episodes` 是去重后的任务数，`rollouts` 是包含随机重复的运行次数；随机重复不会增加任务数或独立场景数。

## 首轮结果（2026-11-03）

输出：`out/active_evidence_20261103_01/report.md`。新增 8 次观察后的正确排序率：

| 表征 | 策略 | 正确排序率 |
|---|---|---:|
| 冻结 CLS 均值 | 随机（3 次重复） | 87.5% |
| 冻结 CLS 均值 | 固定顺序 | 100% |
| 学习记忆，alpha=0 | 学习价值 | 50% |
| 学习记忆，alpha=0.1 | 学习价值 | 50% |

两个价值头的评测 MSE 都高于全零预测。辅助预测的训练误差下降，但未转化为这批任务上的最终识别收益。当前结果说明实现已经可训练、可重放，不支持“流形辅助已改善证据收集效率”的结论。

接下来应先在表征训练位置检查匹配任务能否拟合，并补充独立位置、身份及参考背景的数据；不能根据已查看的 105 位置反复选参数后继续称其为独立测试。本轮尚未接入真实飞行、路径代价或正式停止阈值校准。
